# WTUFengGroup

Welcome to the GitHub organization of the **WTUFengGroup**.

Our research focuses on the development of **analytical methodologies for sample preparation, chromatographic separation, and mass spectrometry-based analysis**, together with **computational tools for metabolomics, submetabolomics, and bioanalytical data analysis**.

🌐 **Group Website:** [Feng Research Group](https://www.x-mol.com/groups/feng_yuqi)

***

This page provides a unified entry point to software and computational tools developed in our published studies. Some software remains hosted in the original developers' GitHub repositories in order to preserve the repository URLs associated with the corresponding publications.

## Published Software

The following software tools were developed as part of our published research.

> **Citation:** If you use any of these tools in your research, please cite the corresponding publication listed below.

### RI-based CPSC

**Retention-index-based chromatographic peak shift correction for untargeted LC-MS metabolomics**

RI-based CPSC is a Python-based tool for chromatographic peak-shift correction and peak alignment using a retention-index system.

- **Repository:** [WHU-Fenglab/RI-based-CPSC](https://github.com/WHU-Fenglab/RI-based-CPSC)
- **DOI:** [10.1021/acs.analchem.3c02583](https://doi.org/10.1021/acs.analchem.3c02583)

**Please cite:**

> *Novel Peak Shift Correction Method Based on the Retention Index for Peak Alignment in Untargeted Metabolomics.*  
> **Analytical Chemistry** (2023).  
> https://doi.org/10.1021/acs.analchem.3c02583

---

### HeuSMA

**Heuristic multigradient LC-MS analysis for improving metabolite coverage and peak identification**

HeuSMA provides computational tools for multigradient LC-MS metabolomics, including the **Heuristic Peak List Generator (HPLG)** and **Heuristic Processor (HP)**.

- **Repository:** [Lacterd/HeuSMA](https://github.com/Lacterd/HeuSMA)
- **DOI:** [10.1021/acs.analchem.4c05315](https://doi.org/10.1021/acs.analchem.4c05315)

**Please cite:**

> *HeuSMA: A Multigradient LC-MS Strategy for Improving Peak Identification in Untargeted Metabolomics.*  
> **Analytical Chemistry** (2025).  
> https://doi.org/10.1021/acs.analchem.4c05315

---

### FAHFA Spectrum Generator

**Theoretical MS/MS spectrum generation and spectral matching for FAHFA structural annotation**

The repository contains the **FAHFA Spectrum Generator** for generating theoretical spectra of DMED-derivatized FAHFAs and a **Cosine Similarity Calculator** for matching experimental and predicted MS/MS spectra.

- **Repository:** [HuanranYin/FAHFA_spectrum_generator](https://github.com/HuanranYin/FAHFA_spectrum_generator)
- **DOI:** [10.1021/acs.analchem.5c05926](https://doi.org/10.1021/acs.analchem.5c05926)

**Please cite:**

> *Mapping C=C Positions in Branched Fatty Acid Esters of Hydroxy Fatty Acids by Oxygen Attachment Dissociation Mass Spectrometry Coupled with Chemical Labeling.*  
> **Analytical Chemistry** (2026).  
> https://doi.org/10.1021/acs.analchem.5c05926

---

### MRM Processor

**Automated processing of targeted LC-MS/MS MRM data**

MRM Processor is a GUI-based software package for automated MRM data processing, including retention-time correction, chromatographic peak detection, peak-area integration, calibration-curve construction, and quantitative analysis.

- **Repository:** [Lacterd/MRM_Processor](https://github.com/Lacterd/MRM_Processor)
- **DOI:** [10.1021/acs.analchem.6c02846](https://doi.org/10.1021/acs.analchem.6c02846)

**Please cite:**

> *MRM Processor: An Integrated Workflow for Automated MRM Data Processing via Relative Retention Time Correction.*  
> **Analytical Chemistry** (2026).  
> https://doi.org/10.1021/acs.analchem.6c02846
